# ElasTech
Este repositório contém o projeto desenvolvido durante o **Bootcamp Elastech**, uma iniciativa da **SoulCode Academy** em parceria com o **PagBank**, voltada para capacitar mulheres em desenvolvimento de software e impulsionar suas carreiras na área da tecnologia.
## 📌 Sobre o Projeto

O objetivo deste projeto é aplicar na prática os conceitos fundamentais do ecossistema Java e Orientação a Objetos aprendidos ao longo do bootcamp.

- **Status do Projeto:** - Em desenvolvimento 
- **Linguagem Principal:** Java

Tecnologias e Ferramentas Utilizadas

- **Java** (JDK 17+)
- **IntelliJ IDEA** — Ambiente de Desenvolvimento Integrado (IDE)
- **Git & GitHub** — Controle de versão e hospedagem de código

- ## 💡 Conceitos Aplicados

Durante o desenvolvimento deste projeto, foram implementados:

- Programação Orientada a Objetos (POO): Abstração, Encapsulamento, Herança e Polimorfismo
- Tratamento de exceções
- Padrões de Projeto (ex: Singleton)
- Estruturas de dados e coleções
